# 🎓 KPI - Постреляційні бази даних

## Лабораторна робота №1 - Об'єктно-орієнтоване програмування

### Предметна область: **Транспортні засоби**

### Завдання

Обрати предметну область і розробити програму на будь-якій мові високого рівня, яка демонструє концепції ООП (успадкування, поліморфізм, інкапсуляцію) і містить:

- **успадкування від абстрактного класу**
- **публічні та приватні властивості і методи**
- **перевантаження методів базового класу**
- **властивості:**
  - простих типів даних (string, int, double)
  - посилання на інші об'єкти
  - масиви/списки простих типів/об'єктів
- **код для створення об'єктів усіх можливих класів, заповнення усіх їх властивостей та виклик усіх методів**

Усі класи, об'єкти, їх властивості та методи повинні мати сенс.

Engine (допоміжний клас)

### Класи та їх призначення

#### 1. **Engine** - Клас двигуна

- **Приватні поля:** `_isRunning` (bool)
- **Публічні властивості:** `Type` (string), `HorsePower` (int)
- **Методи:** `Start()`, `Stop()`, `IsRunning()`, `ToString()`

#### 2. **Vehicle** - Абстрактний базовий клас

- **Публічні властивості простих типів:**
  - `Brand` (string) - марка
  - `Model` (string) - модель
  - `Year` (int) - рік випуску
  - `Color` (string) - колір
- **Посилання на інший об'єкт:**
  - `VehicleEngine` (Engine) - двигун
- **Приватні поля:**
  - `_mileage` (double) - пробіг
  - `_currentSpeed` (double) - поточна швидкість
- **Колекції:**
  - `TripHistory` (List<string>) - історія поїздок
- **Віртуальні методи для перевантаження:**
  - `Start()`, `Stop()`, `Move()`
- **Абстрактні методи:**
  - `GetMaxSpeed()` - максимальна швидкість
  - `DisplayInfo()` - виведення інформації

#### 3. **Car** - Клас автомобіля

- **Додаткові властивості:**
  - `BodyType` (string) - тип кузова
  - `Passengers` (List<string>) - список пасажирів
- **Приватні поля:**
  - `_maxPassengers` (int) - максимальна кількість пасажирів
- **Перевантажені методи:**
  - `Start()` - з перевіркою систем безпеки
  - `Stop()` - базовий функціонал
  - `Move()` - рух по дорозі
- **Додаткові методи:**
  - `AddPassenger()` - додавання пасажира

#### 4. **Motorcycle** - Клас мотоцикла

- **Додаткові властивості:**
  - `MotorcycleType` (string) - тип мотоцикла
- **Приватні поля:**
  - `_requiredGear` (string[]) - необхідне обладнання
- **Перевантажені методи:**
  - `Start()` - з перевіркою обладнання
  - `Stop()` - з опусканням підніжки
  - `Move()` - маневрування між автомобілями
- **Додаткові методи:**
  - `PerformTrick()` - виконання трюку

#### 5. **Truck** - Клас вантажівки

- **Додаткові властивості:**
  - `LoadCapacity` (double) - вантажопідйомність
  - `Cargo` (List<string>) - список вантажів
- **Приватні поля:**
  - `_currentLoad` (double) - поточне навантаження
- **Перевантажені методи:**
  - `Start()` - базовий функціонал
  - `Stop()` - зупинка двигуна трака
  - `Move()` - перевезення вантажу
- **Додаткові методи:**
  - `LoadCargo()` - завантаження вантажу
  - `GetCurrentLoad()` - отримання поточного навантаження

## 🔧 Демонстрація концепцій ООП

### 1. **Успадкування від абстрактного класу**

```csharp
public abstract class Vehicle
{
    // Абстрактні методи
    public abstract double GetMaxSpeed();
    public abstract void DisplayInfo();
}

public class Car : Vehicle
{
    // Реалізація абстрактних методів
    public override double GetMaxSpeed() => 220.0;
    public override void DisplayInfo() { /* ... */ }
}
```

### 2. **Інкапсуляція**

```csharp
public class Vehicle
{
    // Публічні властивості
    public string Brand { get; set; }

    // Приватні поля
    private double _mileage;
    private double _currentSpeed;

    // Публічні методи для доступу до приватних даних
    public double GetMileage() => _mileage;
}
```

### 3. **Поліморфізм**

```csharp
// Масив базового типу
Vehicle[] vehicles = new Vehicle[] { car, moto, truck };

// Поліморфний виклик методів
foreach (Vehicle vehicle in vehicles)
{
    vehicle.Start();
    vehicle.DisplayInfo();
}
```

### 4. **Перевантаження методів**

```csharp
// Базовий клас
public virtual void Start()
{
    Console.WriteLine($"\n{Brand} {Model} запускається...");
    VehicleEngine.Start();
}

// Похідний клас
public override void Start()
{
    Console.WriteLine("  Перевірка систем безпеки...");
    base.Start(); // Виклик базового методу
}
```

## Типи властивостей

### Прості типи даних

- `string` - Brand, Model, Color, BodyType
- `int` - Year, HorsePower, \_maxPassengers
- `double` - \_mileage, \_currentSpeed, LoadCapacity
- `bool` - \_isRunning

### Посилання на інші об'єкти

- `Engine VehicleEngine` - двигун транспортного засобу

### Масиви/списки простих типів

- `List<string> TripHistory` - історія поїздок
- `List<string> Passengers` - список пасажирів
- `List<string> Cargo` - список вантажів
- `string[] _requiredGear` - необхідне обладнання

## Демонстраційний сценарій

Програма демонструє:

1. **Створення об'єктів усіх класів:**

   - Автомобіль Toyota Camry 2022
   - Мотоцикл Harley-Davidson Street 750 2021
   - Вантажівка Volvo FH16 2023

2. **Заповнення властивостей:**

   - Додавання пасажирів до автомобіля
   - Завантаження вантажу до вантажівки
   - Запис поїздок у історію

3. **Виклик усіх методів:**

   - Запуск/зупинка транспортних засобів
   - Рух з різними швидкостями
   - Специфічні дії (трюки, завантаження)
   - Виведення детальної інформації

4. **Поліморфізм:**
   - Обхід масиву транспортних засобів
   - Виклик методів через базовий клас

## Результат

Програма успішно демонструє наступні концепції ООП:

✅ **Успадкування** - всі класи наслідують від абстрактного Vehicle  
✅ **Поліморфізм** - перевизначення методів у похідних класах  
✅ **Інкапсуляція** - приватні поля з публічними методами доступу  
✅ **Абстрактні класи** - Vehicle з абстрактними методами  
✅ **Різні типи властивостей** - прості типи, посилання, колекції  
✅ **Перевантаження методів** - Start(), Stop(), Move() у кожному класі
