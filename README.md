# 🎓 KPI - Постреляційні бази даних

## Лабораторна робота №2 ObjectScript - Робота з глобалами

### Предметна область: **Транспортні засоби**

### Завдання

Обрати предметну область і спроєктувати для неї глобал так, щоб у ньому
було принаймні 4 індекси, хоча б трьох різних типів даних. Використати в якості
значень вузлів глобала 2 різних види списків. Показати використання принаймні 4
різних функцій роботи з глобалами. Усі параметри повинні вводитися з клавіатури,
а не жорстко кодуватися в програмі. Глобал і функції роботи з ним повинні мати
сенс.

- **4 індекси різних типів:**

  - `тип` (string) - "Автомобіль", "Мотоцикл", "Вантажівка"
  - `марка` (string) - "Toyota", "BMW", "Harley-Davidson"
  - `модель` (string) - "Camry", "X5", "Street 750"
  - `рік` (number) - 2021, 2022, 2023

- **2 види списків:**

  - Системний список ($ListBuild) - для характеристик
  - Рядковий список (з розділювачем "/") - для обладнання

- **Функції роботи з глобалами:**

  - `$DATA` - перевірка існування вузла
  - `$ORDER` - обхід індексів
  - `$QUERY` - обхід дерева
  - `$QSUBSCRIPT` - отримання індексів
  - `$QLENGTH` - кількість індексів
  - `$GET` - безпечне отримання значення

- **Додаткові функції для списків:**

  - `$LISTBUILD`, `$LIST`, `$LISTVALID`, `$LISTLENGTH`, `$LISTGET`,
  - `$LENGTH`, `$PIECE`

### Запуск ObjectScript програми

1. Встановити InterSystems IRIS (Docker):

   ```bash
   docker run -d --name iris -p 52773:52773 intersystemsdc/iris-community
   ```

2. У VS Code встановити розширення "InterSystems ObjectScript"

3. Завантажити файл на сервер:

   - Відкрийте `Vehicles.mac`
   - Натисніть `Ctrl+Alt+L`

4. Запустити програму:
   - `Ctrl+Shift+P` → "ObjectScript: Open Terminal"
   - Введіть: `Do ^Vehicles`

## Структура глобала

```
^Vehicles(тип, марка, модель, рік) = системний список [колір, тип_кузова, двигун, потужність, макс_швидкість]
^Vehicles(тип, марка, модель, рік, "обладнання") = рядковий список "елемент1/елемент2/елемент3"
^Vehicles(тип, марка, модель, рік, "поїздки") = системний список поїздок
^Vehicles(тип, марка, модель, рік, "пробіг") = число
^Vehicles(тип, марка, модель, рік, "вантажопідйомність") = число (тільки для вантажівок)
```

## Використані функції роботи з глобалами

### 1. **$DATA(variable, target)**

```objectscript
Set exists = $Data(^Vehicles(type,brand,model,year))
```

- Перевіряє існування вузла
- Використовується при додаванні нового засобу та пошуку

### 2. **$ORDER(variable, direction, target)**

```objectscript
Set brand = $Order(^Vehicles(searchType,brand))
```

- Повертає наступний індекс у відсортованому порядку
- Використовується для обходу всіх транспортних засобів певного типу

### 3. **$QUERY(reference, direction, target)**

```objectscript
Set ref = $Query(@ref)
```

- Повертає посилання на наступний вузол у дереві
- Використовується для перегляду всіх транспортних засобів

### 4. **$QSUBSCRIPT(namevalue, intexpr)**

```objectscript
Set type = $QSubscript(ref,1)
Set brand = $QSubscript(ref,2)
```

- Витягує окремі індекси з повного посилання
- Використовується при обході дерева

### 5. **$QLENGTH(namevalue)**

```objectscript
Set level = $QLength(ref)
```

- Повертає кількість індексів у вузлі
- Використовується для фільтрації рівнів вкладеності

### 6. **$GET(variable, default)**

```objectscript
Set mileage = $Get(^Vehicles(type,brand,model,year,"пробіг"),0)
```

- Безпечно отримує значення вузла або значення за замовчуванням
- Використовується для отримання пробігу та обладнання

## Використані функції роботи зі списками

### Системні списки:

1. **$LISTBUILD(element[,element]...)**

```objectscript
Set ^Vehicles(type,brand,model,year) = $ListBuild(color,bodyType,engineType,power,maxSpeed)
```

2. **$LIST(list, position)**

```objectscript
Set color = $List(info,1)
```

3. **$LISTVALID(exp)**

```objectscript
If '$ListValid(trips) { Set trips = $ListBuild() }
```

4. **$LISTLENGTH(list)**

```objectscript
Set tripCount = $ListLength(trips)
```

5. **$LISTGET(list, position, default)**

```objectscript
Set tripInfo = $ListGet(trips,i,"")
```

### Рядкові списки:

7. **$LENGTH(list, delimiter)**

```objectscript
Set equipCount = $Length(equip,"/")
```

8. **$PIECE(list, delimiter, from, to)**

```objectscript
Set item = $Piece(equip,"/",i)
```

## Функціонал програми

1. **Додавання транспортного засобу** - всі параметри вводяться з клавіатури
2. **Перегляд всіх засобів** - обхід глобала з виведенням характеристик
3. **Пошук засобу** - пошук за 4 індексами
4. **Додавання поїздки** - робота зі списками поїздок
5. **Перегляд поїздок** - виведення історії поїздок
6. **Статистика** - підрахунок кількості та середнього пробігу
7. **Видалення** - використання команди Kill
